# 04 · PPO 与 SAC

这一章讲本项目实现的两种算法。思路部分不涉及数学推导，代码部分对照
`robotrl/algorithms/` 下的文件。

## 先分两大类

强化学习算法可以粗分成两类，区别在于**数据能不能重复利用**。

**同策略（on-policy）**：用当前策略刚产生的数据来更新当前策略。数据用完就丢，
因为策略一更新，之前的旧数据就"过期"了——它是在别的策略下产生的。
PPO 属于这一类。

**异策略（off-policy）**：把历史数据都存起来，从中采样来更新。数据可以反复使用，
样本效率高得多。SAC 属于这一类。

这个区别决定了两件事：**采样效率**（SAC 明显更高）和**实现复杂度**（SAC 需要
处理"数据来自旧策略"带来的偏差）。

本项目两个都实现，可以直接对照。

## 策略梯度：往能拿高分的方向调

上一章说过，策略是个网络，输出动作分布的参数。训练的目标是让期望回报最大。

思路很直接：跑一批数据，看看哪些动作之后拿到的回报高，就提高这些动作的概率；
回报低的就降低。

```
loss = -log(策略输出该动作的概率) × 这个动作之后拿到的回报
```

回报高的时候，为了降低 loss，网络会提高这个动作的概率。反过来就降低。

但直接这么用有个大问题：**回报的绝对值不稳定**。这一批数据的回报都是 100，
和都是 -5，梯度方向应该是一样的——我们关心的是相对好坏。所以实际用的是
**优势**（advantage）：这个动作比该状态下的平均水平好多少。

```
优势 A = 实际拿到的回报 − 预期能拿到的回报（用价值网络估计）
```

A 为正说明这个动作超预期，应该鼓励；为负则应该抑制。优势怎么算更准，是各个
算法的核心区别之一。

## PPO：限制每次更新的幅度

策略梯度有个隐患：一次更新迈得太大，策略可能直接崩掉，之后产生的数据全是垃圾，
再也回不来。

PPO 的做法是**限制新旧策略的差异**。它定义概率比：

```
ratio = 新策略选择该动作的概率 / 旧策略选择该动作的概率
```

ratio 等于 1 表示策略没变。PPO 的损失函数在 ratio 偏离 1 太多时就不再提供梯度：

```python
# 伪代码
surrogate = ratio * advantage
clipped   = clip(ratio, 1 - ε, 1 + ε) * advantage
loss = -min(surrogate, clipped)
```

`ε` 通常取 0.2。效果是：**只在旧策略附近的一小块区域内更新**，超出去的部分不
再被鼓励。这样每次更新都是可控的，训练稳定得多。

PPO 之所以成为机器人控制的事实标准，很大程度上就因为这个稳定性——它不像某些
算法那样需要精细调参才能跑起来。

### PPO 里必须做对的那些细节

算法思想只有上面几句，但从论文到能跑通的代码之间隔着一堆实现细节（业界总结为
三十多条，本项目实现了其中关键的十几条）。漏掉任何一条，训练可能不崩，但效果
明显变差，而且极难定位。

**广义优势估计（GAE）**：优势不是只用一步回报算，而是用多步的加权组合，权重由
`lam`（通常 0.95）控制。它平衡了偏差和方差——步数少偏差大，步数多方差大。

**超时截断要用 bootstrap**：回合因为超时而结束时，最后一步的价值估计**不能置零**。
超时意味着"这一回合没结束，只是我们不继续采样了"，后面的回报仍然存在。而因摔倒
终止时，价值确实是 0。这两者混为一谈，价值估计会凭空掉一个台阶。
本项目在 `StepResult` 里把 `terminated` 和 `truncated` 分成两个字段，就是为了
这件事。

**优势归一化**：把一批数据的优势标准化成均值 0 方差 1。因为优势的绝对尺度随
训练变化，不归一化的话学习率得跟着变。

**观测归一化**：滑动统计观测的均值和方差。观测分布会随训练漂移（策略变强后走的
地方不一样了），固定统计量会让后期观测落在归一化范围外。

**价值损失裁剪**：价值网络的更新同样限制幅度。理由和策略侧一样——价值估计突然
跳变会让优势算错，进而把策略带偏。

**双学习率**：actor 用 3e-4，critic 用 1e-3。critic 要拟合的是回归问题，比策略
的优化问题简单，可以学得快些。

**自适应学习率**：监控新旧策略的 KL 散度，超过目标值就降低学习率，低于目标值的
一半就提高。这是调参时最省事的一个机制。

**正交初始化**：参数用正交矩阵初始化，让信号在深层网络中前向和反向传播时保持
方差稳定。策略网络的输出层还有特殊处理——初始时输出接近 0，让初始策略的行为
接近"保持默认姿态"，而不是一上来就乱动。

**梯度裁剪**：限制梯度的范数上限，防止个别极端样本把参数带飞。

这些细节在 `robotrl/algorithms/ppo.py` 里逐条实现，每条都有注释说明它在防什么。
**建议的读法是先读 loss 的主体部分理解算法，再逐条看这些细节**——一次性全看
容易迷失在细节里。

## SAC：把探索写进目标函数

SAC 走的是另一条路。它的目标函数里除了回报，还有一项**熵**：

```
目标 = 回报 + α × 策略的熵
```

熵衡量策略的随机程度。加上这一项，策略在追求高分的同时还被要求"保持一定的随机
性"。这个设计的妙处在于：**探索不再需要人工调节，而是被自动纳入优化目标**。
训练初期策略随机性高、充分探索；随着训练进行，如果需要更确定的行为才能拿高分，
策略会自己降低随机性。

温度系数 `α` 控制两项的相对权重，SAC 可以自动调节它（`auto_alpha`），这让 SAC
少了一个最烦人的调参维度。

### SAC 里必须做对的那些细节

**双 Q 网络取最小值**：SAC 学两个 Q 网络，更新时取两者估计的较小值。原因是 Q 网络
会系统性高估——它是在自己估计的目标上训练的，偏差会累积。取最小值是对高估的
直接抑制。

**tanh 修正（最容易漏的一条）**：SAC 的策略输出经过 tanh 压缩到 `[-1, 1]`。但
概率密度经过非线性变换后要乘以雅可比行列式才能保持归一化：

```
log π(a|s) = log μ(u|s) − Σ log(1 − tanh²(u))
```

漏掉后面那一项，算法不会崩，只是策略会倾向于把动作推到饱和区（因为那里概率
密度被错误地算小了）。表现是机器人动作发抖、贴着极限跑。

**目标网络软更新**：Q 网络的目标值用另一个"滞后"的网络算，每次只往当前网络挪
一小步（`tau=0.005`）。直接用当前网络算目标会导致目标跟着预测一起动，训练不稳定。

**策略延迟更新**：Q 网络更新两次，策略才更新一次。Q 估计不准的时候更新策略，
会把错误放大。

**回放池预热**：先随机采集几千步再开始学习。池子里数据太单一就更新，网络会过拟合
早期那点数据。

**层归一化**：SAC 对观测尺度比较敏感（Q 网络要拟合的目标变化剧烈），加一层
LayerNorm 让训练稳得多。

## 两个算法怎么选

| | PPO | SAC |
| --- | --- | --- |
| 数据类型 | 同策略，用完即弃 | 异策略，回放池复用 |
| 样本效率 | 低，需要更多交互 | 高，同样的步数学得更多 |
| 稳定性 | 很稳，超参不敏感 | 较敏感，调不好会发散 |
| 训练速度 | 采样和更新都是批量矩阵运算，快 | 每步多一次回放采样和四个网络更新，慢 |
| 适用场景 | 并行环境多、仿真便宜 | 交互昂贵、真实机器人上训练 |

本项目的选择是**两个都实现，并提供对照实验**（`configs/train/` 下有对应的配置）。
在仿真里环境便宜，PPO 通常是更省时的选择；但如果要往真机迁移、交互成本高，
SAC 的样本效率就更重要。

## 代码结构：四件套正交

`robotrl/algorithms/` 下的划分是刻意设计的，让换算法时改动最小：

```
networks.py     网络结构     PPO 用 actor-critic；SAC 用双 Q + 策略网络
storage.py      经验存放     PPO 用 RolloutStorage；SAC 用 ReplayBuffer
ppo.py/sac.py   算法本体     损失函数与更新规则，两个文件互不依赖
trainer.py      训练循环     采样、日志、评估、存档，两种算法共用框架
```

好处是各个维度可以独立替换：想换网络结构只改 `networks.py`；想试新算法，只要
它遵循同样的存放和训练约定，就能直接接进来。

`base.py` 里的 `Policy` 和 `Trainer` 是这三个文件的共同接口，也是部署层依赖的
契约——**部署层不知道策略是用 PPO 还是 SAC 训出来的**，它只要求策略能接受观测、
输出 `[-1, 1]` 的动作。

## 动手试试

理解这些细节最好的方式是**关掉它，看会发生什么**。代码里每条实现细节都能通过
配置或改一行代码关掉，建议按这个顺序试：

1. 关掉超时 bootstrap：把 `truncated` 当 `terminated` 处理，观察价值曲线是否出现
   规律性的锯齿
2. 关掉优势归一化：看学习率是否变得敏感
3. SAC 里去掉 tanh 修正项：观察动作是否逐渐贴到极限值

每次只改一处，跑 toy 环境几十秒就能看出差别。
