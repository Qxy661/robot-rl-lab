# 文档

这里有两条阅读路线，写给两类不同的读者。你可以按自己的背景选一条。

## 零基础路线

如果你几乎没有编程或机器学习基础，从 00 顺着读下去。七章构成一个台阶，每章
建立在前一章之上，读完一章再读下一章。

| 章节 | 回答什么问题 | 读完能做到 |
| --- | --- | --- |
| [00 背景知识](00_背景知识.md) | 读这份代码需要哪些 Python 知识 | 看懂 `spec.py`、`contracts.py` |
| [01 神经网络与 PyTorch](01_神经网络与PyTorch.md) | 网络是怎么"学"的 | 看懂策略网络的定义和训练循环 |
| [02 强化学习基础](02_强化学习基础.md) | 没有标准答案时怎么学 | 看懂环境循环、观测、奖励设计 |
| [03 物理仿真与机器人](03_物理仿真与机器人.md) | 环境是哪来的，PD 控制是什么 | 看懂 MuJoCo 模型与关节映射 |
| [04 PPO 与 SAC](04_PPO与SAC.md) | 具体怎么更新策略网络 | 看懂算法实现和每个实现细节的用意 |
| [05 跨形态抽象](05_跨形态抽象.md) | 换机器人要改什么 | 加一种新形态 |
| [06 部署与量化](06_部署与量化.md) | 策略怎么上设备，代价多大 | 跑完导出到回测的全流程 |

要注意的是，这条路线走下来需要持续投入，不是读一遍的事。**真正的理解来自对着
代码读、改一改、看会发生什么**。每章末尾都给了可以动手的地方。

## 有 ML 背景的路线

如果你已经熟悉强化学习和 PyTorch，跳过前四章，直接看这几篇：

- [05 跨形态抽象](05_跨形态抽象.md)：契约驱动的设计，换形态只改配置
- [06 部署与量化](06_部署与量化.md)：量化回测闭环，这是本项目与同类项目差别最大的部分
- 各模块目录下的 docstring：每个文件的头部都写了它解决什么问题、为什么这么设计

## 项目外的补充

- 想先跑起来看效果：回到根目录 [README](../README.md) 的快速开始
- 想直接看代码：`robotrl/` 下按 `assets` → `envs` → `algorithms` → `deploy`
  的顺序读，这个顺序也是数据流的顺序
